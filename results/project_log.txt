[13] "Leukemia is a type of blood cancer that affects blood-forming tissues. Different leukemia types have different biological characteristics. This study investigates the use of gene expression data and machine learning for classifying ALL and AML. The Golub leukemia dataset was obtained through the Bioconductor package golubEsets. It contains 7,129 gene probes and 72 samples, including 47 ALL and 25 AML samples. Exploratory analysis was performed using statistical summaries, histograms, boxplots, Principal Component Analysis and a gene expression heatmap. A Support Vector Machine with a linear kernel was developed using the 100 most variable genes. The model achieved 90.48% accuracy on the held-out test set and 92.16% accuracy during five-fold cross-validation. These findings demonstrate the potential of gene expression analysis for leukemia classification. Further validation using independent datasets is required."
